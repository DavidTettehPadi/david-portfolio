About Me

Healthcare professional, developer in progress.

I'm David Tetteh Padi, a licensed Mental Health Officer transitioning into web development and technology.

My background in healthcare has strengthened my ability to understand people, solve problems, communicate clearly and work responsibly with sensitive information.

I'm now applying those skills to software development, with a growing focus on building responsive and user-friendly web applications.

I started with HTML and CSS and have progressed into Tailwind CSS and JavaScript. My current goal is to develop stronger frontend, backend and database skills so I can build complete full-stack applications.

I believe good software should not only work. It should be clear, accessible and useful to the people who interact with it.
